# Исходные данные

Рабочий файл `URSS_Obstacles_2.txt` хранится отдельно от репозитория. Путь задаётся параметром `--input`.

Это текст с разделителями-табуляциями и заголовками столбцов. Пустые поля сохраняют свои позиции. Для обработки нужны ID, время, высота объекта, его координаты относительно камеры, опорные геодезические координаты, собственное положение и углы ориентации.

Файлы `.txt` и архивы из этой папки исключены из Git. Встроенный пример и тесты используют небольшие искусственные данные.
