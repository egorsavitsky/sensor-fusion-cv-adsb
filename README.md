# Гармонизация данных СТЗ и АЗН-В

Проект по практике в ГосНИИАС. Программа сопоставляет препятствия из двух источников по трёхмерным координатам и времени.

Сейчас используется лог `URSS_Obstacles_2.txt`. Отдельного лога АЗН-В нет, поэтому второй поток моделируется из опорных координат `Obs.Lat/Lon/Alt` с добавлением шума, задержек и потерь сообщений.

## Запуск

Нужен компилятор C++17. Для Windows с MinGW:

```powershell
.\build.ps1 -Test
.\build\fusion_core.exe --input "..\Конфликты\URSS_Obstacles_2.txt" --assignment optimal
```

Без аргументов запускается небольшой пример. Исходный лог хранится отдельно от репозитория.

Полезные параметры:

- `--summary build\summary.csv` — сохранить итоговые метрики;
- `--matches build\matches.csv` — сохранить пары, объекты без пары и координаты в ENU;
- `--benchmark` — сравнить время исходного и оптимизированного расчёта;
- `--help` — посмотреть остальные настройки.

Для выгрузки нужно указать новое имя файла: существующие CSV не перезаписываются.

## Как работает

1. Записи лога объединяются в кадры по метке времени, включая кадры без препятствий.
2. Координаты камеры переводятся в ENU с учётом положения и ориентации ВС. Смещение камеры оценивается по первым 1000 кадрам; эти кадры не участвуют в проверке.
3. Для модельного АЗН-В создаются отдельные ID. Связь с исходными ID используется только для оценки результата.
4. К каждому кадру подбираются уже принятые сообщения АЗН-В, затем назначаются пары на расстоянии меньше 15 м.

По умолчанию назначение жадное. Параметр `--assignment optimal` включает венгерский алгоритм. В режиме `--offline` разрешена интерполяция между соседними измерениями, в том числе с использованием будущей точки.

Для камеры приняты оси X вправо, Y вверх, Z вперёд и привязка к центру объекта. Высоты трактуются как эллипсоидальные WGS84. Это допущения для текущего лога; оценённое смещение не является измеренной установкой камеры.

В расчёте расстояний вместо `pow` используются умножения, далёкие пары отсекаются до вычисления корня. Матрицы преобразования готовятся один раз на кадр.

## Проверка на логе

Проверены все 23 725 кадров, из них 1000 отведены на оценку смещения. Результаты с модельным АЗН-В при настройках по умолчанию и seed 42:

| Назначение | Precision | Смены ID |
| --- | --- | --- |
| Жадное | 98,11% | 272 |
| Глобальное | 99,59% | 66 |

RMSE координат после поправки смещения — 3,72 м. Оптимизированная жадная ассоциация в замере на MinGW GCC 6.3.0 с `-O2` работала примерно в 1,27 раза быстрее исходного расчёта.

В данном логе препятствия неподвижны, меняется положение собственного ВС. Проверка на независимых данных АЗН-В пока не проводилась.
