# Cлияние данных: АЗН-В + СТЗ

Первая версия алгоритма комплексирования (Track-to-Track 3D Association). 
Написана для отладки математики и логики работы до получения реальных логов.

Код в `main.cpp` реализует три этапа:
1. **Синхронизация по времени:** Линейная 3D-интерполяция точек АЗН-В для точной подгонки под таймстемпы кадров камеры.
2. **Оценка вероятности:** Вычисление Евклидова 3D-расстояния между объектами с линейной нормализацией в вероятность. Задан жесткий порог отсечения в 15 метров.
3. **Ассоциация:** Использован жадный алгоритм для связывания наиболее вероятных пар «один к одному» с защитой от двойного назначения.

В `main()` использован пробный вариант данных для демонстрации работы. Как только будут даны нужные логи, этот блок будет заменен на парсер файлов.
