# Гармонизация данных СТЗ и АЗН-В

Программа сопоставляет препятствия в зоне аэродрома. Для каждого объекта она строит прямоугольник по координатам, габаритам и курсу. Степень совпадения (IoU) равна площади пересечения двух прямоугольников, делённой на площадь их объединения.

Во встроенном примере самолёт и машина движутся разными курсами. Можно также обработать запись СТЗ `URSS_Obstacles_2.txt`. В обоих случаях поток АЗН-В модельный.

## Запуск в Windows

Нужен компилятор `g++` с поддержкой C++17. Откройте PowerShell в папке `sensor-fusion-cv-adsb`, где лежит `build.ps1`.

```powershell
.\build.ps1 -Test
.\build\fusion_core.exe --demo
```

Пример состоит из 12 кадров. Для каждой пары с IoU от 0,1 программа печатает время, данные обоих объектов и степень пересечения. В конце идут число пар, прошедших порог, число назначений один к одному и количество объектов каждого источника. Чтобы увидеть даже слабые пересечения, задайте `--overlap-threshold 0`.

Следующая команда обрабатывает полную запись с глобальным назначением и сохраняет итоги в CSV.

```powershell
.\build\fusion_core.exe --input "..\Конфликты\URSS_Obstacles_2.txt" --assignment optimal --quiet --summary build\iou-summary.csv
```

`--pairs FILE` сохраняет все положительные пересечения, `--matches FILE` — назначенные пары и объекты без пары. Для повторного запуска с выгрузкой укажите новое имя файла. Остальные параметры перечислены в `--help`.
